基于 QEvasion 与 QNLI 的可复现文本对分类实验


一 实验目的与要求
本实验围绕回答清晰度与问答回避策略展开，目标是把 question 与 interview_answer 组成一个文本对分类任务，区分明确回答、模糊或矛盾回答以及明确不回答。实验同时要求建立传统基线和预训练表示基线，使用 Macro-F1、类别级 Precision、Recall、F1 及混淆矩阵进行评价，并将统一的数据适配、训练和评估流程迁移到 QNLI 问答相关性场景。
理解 response clarity 与 evasion strategy 的概念，并明确高层三分类和细粒度九分类的关系。
复现 TF-IDF + Logistic Regression 与 SentenceTransformer 表示 + Logistic Regression 两类基线。
固定随机种子，保存配置、指标、逐样本概率和预测文件，使实验可以重复运行。
通过 QNLI 迁移验证统一的 text_a / text_b / label 接口，并分析哪些假设可以复用。
二 任务定义与标签体系
任务输入是一条目标子问题 question 及其对应的完整回答 interview_answer，输出是回答清晰度的高层标签。数据中的原始标签为 Clear Reply、Ambivalent 和 Clear Non-Reply；为了与报告表述一致，第二类在本文中记为 Ambivalent Reply。

模型不能只根据回答是否长、是否流畅来判断类别，而应比较问题所要求的信息与回答实际提供的信息。这个要求使本任务区别于普通情感分类，也解释了为什么需要同时编码 question 和 answer。

四 模型、训练配置与复现
4.1 模型设计
基线 A 使用 question + [SEP] + answer 的拼接文本，通过 TF-IDF 提取 unigram 或 unigram+bigram 特征，再训练 Logistic Regression。验证集固定为训练集的 10%，用于选择 n-gram 与 class_weight。基线 B 使用 sentence-transformers/all-MiniLM-L6-v2 分别编码 question 和 answer，得到 384 维归一化向量，并拼接 e_q、e_a、|e_q-e_a|、e_q*e_a 四部分特征形成 1536 维表示，编码器冻结，仅训练带类别权重的 Logistic Regression。

五 实验结果
5.1 模型总体性能

在 QEvasion 测试集上，SentenceTransformer 表示 + LR 的 Macro-F1 为 0.4855，比 TF-IDF + LR 的 0.4351 提高约 0.0504，说明联合语义表示对回答清晰度判断有帮助。多数类基线的 Accuracy 虽为 0.6688，但 Macro-F1 仅 0.2672，验证了类别不均衡下 Accuracy 的误导性。QNLI 迁移结果的 Macro-F1 为 0.5741，不能与三分类原任务直接按绝对值比较，但说明同一套文本对接口和评估流程可以在二分类问答相关性任务中运行。

图中同时列出原任务两个基线、已有的预训练表示基线和 QNLI 迁移结果。最佳原任务模型的混淆矩阵显示，Ambivalent Reply 的识别数量最多，但仍有较多样本被误判为 Clear Reply；Clear Non-Reply 样本少且边界明显，仍是需要重点分析的少数类。
5.2 最佳模型类别级结果

Clear Reply 的 F1 为 0.4571，Ambivalent Reply 的 F1 为 0.6938，Clear Non-Reply 的 F1 为 0.3056。少数类 Clear Non-Reply 的 Recall 虽达到 0.4783，但 Precision 只有 0.2245，说明模型倾向于把部分模糊或部分回答也判为明确不回答。该现象与类别数量少、语言边界重叠及回答中的显式拒答线索不足有关。
六 错误分析
错误分析从 predictions_st_lr.csv 中筛选真实标签与预测标签不一致的样本，并按回答长度、真实类别和混淆方向选择代表性案例。错误并不都来自词汇缺失，很多案例是问题只被部分回答、回答先提供背景再转移主题，或者回答隐含给出结论而没有直接表态。

6.1 主要误差来源
长而空泛：回答的词数很长，但核心信息比例低，TF-IDF 和句向量都可能被高频背景词牵引。
部分回答：一个回答包含多个子问题时只回应其中一项，整体语气可能很肯定，却没有满足全部信息需求。
隐式回答：需要结合上下文才能推出结论，表面没有明确的肯定或否定词，导致模型偏向 Ambivalent Reply。
主题转移与套话：回答通过复述政策、强调原则或引入新议题回避原问题，模型可能把流畅性误当成相关性。
类别边界与噪声：Clear Non-Reply 样本少，Clarification、Claims ignorance 和 Partial/half-answer 的边界会放大预测不稳定。
6.2 可验证的改进假设
加入问题-回答交互特征，例如问题类型、回答中是否覆盖关键实体和否定结构，并比较其对少数类 Recall 的影响。
按 interview title 或 president 做分组交叉验证，检验模型是否依赖人物和主题词，并与随机切分结果对比。
采用 class-balanced loss、阈值校准或少数类过采样，重点观察 Clear Non-Reply 的……

……uestion 与 sentence 组成二分类文本对，判断句子是否包含问题答案。本实验从官方 GLUE QNLI train.tsv 中按固定种子对两个类别各抽取 6,000 条，得到 12,000 条训练样本，并使用 dev.tsv 的 5,463 条作为测试集。字段适配后仍使用 text_a、text_b、label、group、uid 五个统一字段，模型选择、概率输出和评估函数均复用原任务代码。

7.2 迁移分析
政治问答中的回避检测和 QNLI 的答案包含判断都可以抽象为“问题要求的信息”与“第二段文本实际提供的信息”之间的关系判断，因此 text_a/text_b 接口、拼接分隔符、TF-IDF + LR 管线、固定验证集、概率输出和 Macro-F1 评价可以直接复用。不能直接复用的部分包括标签数量和标签语义：QEvasion 的三类标签描述回答清晰度，QNLI 的两类标签描述句子蕴含关系；原任务的 president 分组字段在 QNLI 中也没有对应物。由于标签空间不同，本实验没有把原任务分类器硬套到 QNLI，而是明确记录为“直接迁移不适用”，再进行适配后训练。
QNLI 迁移结果的 Macro-F1 为 0.5741，两个类别 F1 分别为 0.5423 和 0.6058。这个结果的意义不是证明 QNLI 绝对更容易，而是说明统一适配器确实把数据读取、文本对构造、模型选择、评估和预测文件生成串成了可复用流程。迁移时真正需要重新设计的是标签映射、抽样策略和错误解释，而不是整个工程骨架。
八 实验结论
本实验把问答回避检测转化为可评估的文本对三分类任务，并完成了从数据理解、基线建立到跨场景迁移的完整流程。EDA 表明 QEvasion 存在明显的类别不均衡，回答长度远高于问题长度，同一采访包含多个子问题，因此仅依赖 Accuracy 或回答表面词汇都可能得到误导性结论。多数类基线的 Accuracy 达到 0.6688，但 Macro-F1 只有 0.2672，说明 Macro-F1 更适合作为主指标。TF-IDF + LR 提供了可解释的传统基线，SentenceTransformer 冻结表示 + LR 将 Macro-F1 从 0.4351 提升到 0.4855，提升主要来自对文本对语义关系的更好建模，但 Clear Non-Reply 仍然最难识别。典型错误包括长而空泛、部分回答、隐式回答、主题转移和标签边界模糊，后续可从问题类型、关键信息覆盖、分组……
