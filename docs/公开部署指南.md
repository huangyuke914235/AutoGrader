# 公开部署指南（Streamlit Community Cloud 免费版）

> 目标：把学生端这个 demo 变成一个**任何人打开链接就能用**的免费网站，
> 并且网址是能直接发给评委 / 同学的形式，而不是 `localhost`。
>
> 部署平台：**Streamlit Community Cloud**（免费、不限公开应用，队友的
> `autograder-szu.streamlit.app` 就是同一条路）。

---

## 一、部署前三件必须改的事（已改完并验证）

代码能跑不等于能对外开放。**公网上"所有人共用一个目录"就是隐私事故**，
所以先把这三件事钉死：

| 风险 | 本地看着没问题，公网会出事 | 现在的做法 |
|---|---|---|
| 体检档案所有人共用一个目录 | A 同学能在档案列表里看到 B 同学的**报告名和分数** | 每人一个独立空间，编号放在网址里（`?sid=<16位十六进制>`），严格校验后才允许读写 |
| 评阅结果写进服务器磁盘 | `GradingResult` 里含**逐字引用的原文证据**，等于替学生留存作业片段 | 公网模式下**完全不写盘**（`_public_host()`），界面如实告知 |
| 没人来收的目录一直堆在磁盘上 | 免费主机磁盘有限，久了写满 | 每次进程启动清扫一次 7 天没动过的空间 |

配套的两条退路也一起做了：

- **档案导出 / 导入（JSON）**：免费主机的磁盘是**临时**的（应用休眠或重新部署就清空），
  换浏览器、清了网址也找不到原来那间档案柜。所以把数据交回给本人 ——
  界面上有「⬇️ 导出全部档案」和「📥 导入档案」。
- **编号不是密码**：它只是防止"随手就能看到别人"，不是访问控制。
  真要保密的作业，不要在公网站点上传未脱敏的原件（界面上已有这行警告）。

验证脚本（改动后跑一次）：

```
python tools/smoke_public_deploy.py     # 12 项：隔离 / 乱填编号不崩 / 公网不落盘 / 导出导入
python -m pytest -q                     # 全量单测
```

## 二、三步上线

### 第 1 步：在 GitHub 上建一个**空**仓库

- 仓库名建议：`autograder-student`（网址里的名字由它决定，见第 3 步）
- **必须 Public**：Community Cloud 免费版只部署公开仓库
- 勾掉 "Add a README" —— 仓库要空着，否则第一次推送会撞冲突

> ⚠️ 顺手做一件事：GitHub → Settings → Emails → 勾上 **Keep my email addresses private**。
> 本机 git 配置的提交邮箱是 `2050779785@qq.com`，公开仓库的提交记录会把它显示出来，
> 不勾这一项等于把邮箱挂在公网上。

### 第 2 步：把本机这份推上去

仓库已经建好并做了首次提交（在 `autograder_student/` 目录下）。
复制下面两条命令，**把 `<你的GitHub用户名>` 换成你自己的**：

```bash
cd "C:/Users/zhang/LearnBuddy/2026-09-24-10-10-46/autograder_student"
git remote add origin https://github.com/<你的GitHub用户名>/autograder-student.git
git push -u origin main
```

第一次 push 会弹窗让你登录 GitHub，按提示走即可（不需要把令牌贴给我）。

如果默认分支是 `master` 而不是 `main`：

```bash
git branch -M main
```

### 第 3 步：在 Streamlit Cloud 上部署

1. 打开 <https://share.streamlit.io>，用同一个 GitHub 账号登录
2. 右上角 **Create app** → *"Yup, I have an app"*
3. 填：
   - **Repository**：`你的用户名/autograder-student`
   - **Branch**：`main`
   - **Main file path**：`app.py`
   - **App URL（自定义子域名）**：见下面
4. Advanced settings → **Python version**：选 `3.12`（社区版默认，稳妥）
5. Deploy —— 几分钟后就能打开

**网址选哪个**（这一栏就是"让网址一般化"的地方）：

| 填进去的名字 | 最终网址 | 备注 |
|---|---|---|
| `autograder-student` | `https://autograder-student.streamlit.app` | 首选，和队友的教师端 `autograder-szu` 对得上 |
| `exp-report-check` | `https://exp-report-check.streamlit.app` | 更像工具名 |
| `autograder-check` | `https://autograder-check.streamlit.app` | 短，好念 |

子域名全球唯一，被别人占了就换一个。**不填**的话会生成一串带随机哈希的长网址，
就是"不好看、发不出去"的那种 —— 所以一定要填。

## 三、部署后自检（5 分钟）

打开你的网址，逐条确认：

1. **汉化还在**：右上角应该是中文（依赖 `.streamlit/config.toml` 里的
   `enableStaticServing = true`，已在仓库里，不依赖启动命令）
2. **换一个浏览器 / 无痕窗口打开** → 档案列表应该是空的（说明隔离生效，
   不会看到别人或自己上一次的数据）
3. 做一次体检 → 档案里出现记录；点「⬇️ 导出全部档案」能下载 JSON
4. 再开一个无痕窗口 → 导入刚才那个 JSON → 记录回来了
5. 评阅页底部应该写着「公网部署：评阅结果不写入服务器磁盘」

## 四、免费版的真实限制（先说清楚，别到时候措手不及）

| 限制 | 具体表现 | 应对 |
|---|---|---|
| **会休眠** | 闲置一段时间后应用睡过去，下一个人打开要等 30~60 秒冷启动 | 演示前**自己先打开一次**把它唤醒 |
| **磁盘是临时的** | 休眠 / 重新部署 / 换机器，档案可能消失 | 已做成可导出 JSON，界面上也写明了 |
| **1 GB 内存** | 超大 PDF（上百页）可能吃不住 | 上传上限已是 20MB，够用 |
| **仓库必须公开** | 代码谁都看得见 | 密钥从不落盘；`teammate_src/`（队友源码）、`data/`、`_internal/`、含真实姓名的样本清单都已在 `.gitignore` 里 |
| **不能自定义域名** | 只能是 `xxx.streamlit.app` | 要 `autograder.top` 这类自有域名，得换付费主机（约 35~70 元/月）+ 国内服务器还要备案 |
| **没有登录体系** | 任何人都能打开 | demo 阶段可接受；真做权限是另一件事 |

## 五、公网模式下改了哪些行为（`AG_PUBLIC`）

判定逻辑在 `app.py` 的 `_public_host()`：

```
环境变量 AG_PUBLIC=1        → 强制按公网口径跑（本地想复现公网行为时用）
环境变量 AG_PUBLIC=0        → 强制按本地口径跑
都不设                       → 检测 Streamlit Cloud 的挂载目录 /mount/src
```

| 行为 | 本地 | 公网 |
|---|---|---|
| 评阅结果写入 `data/results/` | 写 | **不写**（含原文引用） |
| 体检档案位置 | `data/history/<编号>/` | 同（按人隔离，与本地一致） |
| 上传的临时文件 | 解析后立刻删除 | 同 |

想在本机复现公网行为：`AG_PUBLIC=1 streamlit run app.py`。

## 六、要撤下来怎么办

- 临时下架：Streamlit Cloud → app 设置 → **Delete app**（GitHub 仓库不受影响）
- 彻底删除：把 GitHub 仓库删掉即可
- 只是想换网址：app 设置里改 App URL，随时可改
